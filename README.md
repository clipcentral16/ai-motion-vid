# ai-motion-vid

3D animated videos built with **Three.js** (through `@remotion/three`) and **Remotion** (captions, audio, rendering).

```bash
npm install
npm run dev      # preview in Remotion Studio
npm run render   # -> out/spinning-object.mp4
```

A sample render is in [`examples/spinning-object.mp4`](examples/spinning-object.mp4). See [CLAUDE.md](CLAUDE.md) for the stack conventions.
